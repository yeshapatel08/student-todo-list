# Student To-Do List

A simple and beginner-friendly To-Do List web application built using HTML, CSS, and JavaScript.

## About the Project

The Student To-Do List helps students organize their daily activities by allowing them to add and view tasks in one place.

This project is created as part of learning web development and GitHub collaboration.

## Technologies Used

- HTML – Structure of the application
- CSS – Styling and layout
- JavaScript – Functionality and interaction

## Features

- Add new tasks.
- Display multiple tasks in a list.
- Simple and clean user interface.

## Features to Be Added

- Delete individual tasks.
- Prevent users from adding empty tasks.

These improvements are tracked through GitHub Issues and are open for contributions.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or your browser.
